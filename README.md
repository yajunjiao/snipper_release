# Snipper

轻量级 Windows 截图工具：截图 → 标注 → 保存 / 复制，一个动作闭环。

比系统自带工具更强大，比重型工具更轻快。纯本地运行，无联网、无账号。

## 功能特性

### 截图

- **区域截图**：冻结屏幕后框选，支持二次确认调整——8 个手柄缩放、框内拖动、Enter / 双击 / ✓ 确认、Esc 取消，覆盖多显示器
- **全屏截图**：一键截取当前屏幕
- **窗口截图**：WGC（Windows.Graphics.Capture）增强路径，可穿透遮挡截取被盖住的窗口
- 截图完成后**自动复制到剪贴板**，并弹出托盘气泡通知

### 编辑器标注

- 矩形、箭头、文字、马赛克四种标注工具
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`），覆盖添加、移动、缩放操作
- 颜色（7 种预设 + 自定义）、线宽（2/3/5/8 px）、马赛克强度（8/12/20/32 px）可调
- 矩形 / 马赛克支持四角缩放控制点

### 贴图（Pin）

- 将截图或标注结果**钉在屏幕上**：无边框、置顶、可拖动的悬浮图片窗口
- 左键拖动移动，滚轮缩放（0.1x ~ 4.0x）
- 右键菜单：复制 / 另存为… / 关闭；`Esc` 关闭当前贴图
- 托盘「关闭所有贴图」批量清屏

### 效率与集成

- 全局热键，任意界面随时唤起
- 保存为 PNG / JPG / BMP，自动记忆上次保存目录，时间戳命名
- 多显示器与混合 DPI 深度适配：全程物理像素坐标，高分屏截图不糊不歪
- 系统托盘常驻，主窗口可完全隐藏

## 使用说明

### 全局热键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + A` | 区域截图 |
| `Ctrl + Shift + F` | 全屏截图 |
| `Ctrl + Shift + P` | 贴图（编辑器内，贴的是标注后的最终图像） |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |

### 系统托盘

- **左键**：区域截图
- **双击**：显示主窗口
- **右键**菜单：区域截图 / 全屏截图 / 所有屏幕 / 关闭所有贴图 / 显示主窗口 / 退出

## 系统要求

- Windows 10 / Windows 11（32 位程序，64 位系统可直接运行）
- WGC 窗口截图增强功能需要 Windows 10 1803 及以上

## 已知限制

- 最小化窗口、DRM 内容、独占全屏游戏无法截取（操作系统限制）
- 箭头/文字标注暂不支持缩放控制点；样式修改暂未纳入 Undo
- 单实例运行守卫、开机自启动、快捷键自定义尚未实现
- 贴图暂不支持从剪贴板直接贴图、贴图上再标注（规划中）
- macOS / Linux 平台实现待补充；OCR 处于规划阶段
